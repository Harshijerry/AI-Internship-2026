| Term | Meaning |
| --- | --- |

| **Model** | A trained AI system that can make predictions |

| **RLHF** | Reinforcement Learning from Human Feedback |
| **Lidar** | Light Detection and Ranging — sensor for self-driving cars |
| **GPU** | Graphics Processing Unit — hardware that accelerates AI training |
