# 🧠 MoodMentor - AI Mental Health Companion

An AI-powered mental health companion that analyzes emotions from text and facial expressions, provides therapeutic responses, and tracks mood patterns over time.

## ✨ Features

- 💬 **AI Chat Therapist** - Compassionate responses using Google Gemini
- 📸 **Face Emotion Detection** - Analyze facial expressions using OpenCV
- 📝 **Text Sentiment Analysis** - VADER + TextBlob for emotion detection
- 📊 **Mood Dashboard** - Track mood patterns with interactive charts
- 🔮 **Mood Prediction** - ML-based next-day mood forecasting
- 🚨 **Crisis Detection** - Immediate helpline suggestions
- 💡 **Coping Strategies** - Personalized suggestions based on emotion
- ✨ **Daily Affirmations** - AI-generated positive affirmations

## 🎯 Why MoodMentor?

Mental health is a critical global issue. MoodMentor makes emotional support:
- **Accessible** - Available 24/7, free to use
- **Private** - No data leaves your device
- **Smart** - Combines multiple AI techniques
- **Safe** - Crisis detection with professional referrals
